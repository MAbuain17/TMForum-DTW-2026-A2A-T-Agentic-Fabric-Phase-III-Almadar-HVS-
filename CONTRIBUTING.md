# Contributing

Use Python 3.11 or later and run `python -m unittest discover -s tests -v` before submitting changes. Keep domain execution in adapters and operator decisions in the runtime. A new scenario should exercise a distinct decision or failure path and include a behavioural test.

Use synthetic fixtures. Do not add meeting minutes, credentials, customer records, internal working decks or vendor documents. Link public references and explain what they inform. Keep protocol compatibility claims tied to an actual tested integration.

## Adaptation boundary

The HVS1 structure and fabric responsibilities come from the sources above. The Tripoli cluster, cell/backhaul IDs, subscriber count, optical fault, backup-path recovery and numerical KPIs are original synthetic fixtures. Core checks are a local operator adapter, not a claim of a named vendor’s delivered agent. This repository does not establish an official Almadar deployment, a final operator-specific commercial use case, or a contribution beyond participation in the Catalyst.

The full folder was inventoried, and text was extracted from its supported document formats. Video recordings and Microsoft Loop files are not treated as fully reviewed evidence. The source choices above are the inspectable basis for the code rather than a claim that every file was exhaustively interpreted.
